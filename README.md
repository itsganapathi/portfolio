# GANAPATHI S — Portfolio Website

A responsive personal portfolio built with **HTML, CSS, and vanilla JavaScript**. Includes bold typography, dark/light themes, theme persistence, scroll-reveal animations, projects, experience, skills, contact links, and a downloadable resume.

## Folder structure

```text
ganapathi-portfolio-project/
├── index.html               # Main page and semantic content
├── css/
│   └── style.css            # Layout, typography, dark/light themes, responsiveness
├── js/
│   └── main.js              # Theme toggle and scroll animations
├── assets/
│   ├── favicon.svg          # Browser tab icon
│   └── GANAPATHI_S.pdf      # Downloadable resume
├── .gitignore
└── README.md
```

## Run locally

Open `index.html` in a browser, or use VS Code's Live Server extension. No build process or npm dependencies are needed. Google Fonts requires an internet connection; the site otherwise works locally.

## Customize

- Update portfolio content and links in `index.html`.
- Update theme variables, colors, bold text, and responsive layout in `css/style.css`.
- Update the theme toggle and scroll animations in `js/main.js`.
- Replace `assets/GANAPATHI_S.pdf` to update the resume.

## Deploy

Upload the entire folder to GitHub Pages, Netlify, or Vercel. Keep the directory structure intact so relative links work.
